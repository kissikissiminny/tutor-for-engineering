1. 1D Constant Acceleration Kinematics

ความเร็ว-เวลา
$v = u + at$
ตำแหน่ง-เวลา
$s = ut + \frac{1}{2}at^2$
ความเร็ว-ระยะทาง (ไร้เวลา)
$v^2 = u^2 + 2as$
ความเร็วเฉลี่ย
$s = \left(\frac{u + v}{2}\right)t$

2. Work-Energy & Conservation

Kinetic Energy
$K = \frac{1}{2}mv^2$
Potential Energy
$U_g = mgh$
Work of Force
$W = \vec{F} \cdot \Delta\vec{r} = F \Delta r \cos\theta$
Work-Energy Principle
$W_{\text{nc}} = \Delta E_{\text{mech}} = E_2 - E_1$
Case Studies: ผลงานการวิเคราะห์โจทย์ (sessions/)
Case 1: แรงต้านทานเฉลี่ยในการเบรกรถยนต์
✓ Solved • Verified
"รถยนต์มวล 1000 kg วิ่งด้วยความเร็ว 20 m/s เหยียบเบรกจนหยุดนิ่งในระยะทาง 50 เมตร จงหาแรงต้านทานเฉลี่ย"
✓ 1. Identify
✓ 2. Model (FBD)
✓ 3. Governing Eq
✓ 4. Sanity Check
สมการหลัก: $v^2 = u^2 + 2as \implies a = -4\ \text{m/s}^2$ และ $\Sigma F = ma$
คำตอบสุดท้าย: $\bar{F}_{\text{res}} = -4000\ \text{N}$ (แรงต้านขนาด $4\ \text{kN}$ ทิศตรงข้ามการเคลื่อนที่)
Sanity Check: มิติ $[M L T^{-2}] = [\text{N}]$ และแรงคิดเป็น $\approx 0.4\times$ น้ำหนักรถ ($mg$) สมเหตุสมผลกับสัมประสิทธิ์ยางรถยนต์
Case 2: ความสูงสูงสุดของวัตถุขว้างแนวดิ่ง
✓ Solved • Verified
"ขว้างก้อนหินมวล 2 kg ขึ้นไปในแนวดิ่งด้วยความเร็วต้น 30 m/s จงหาความสูงสูงสุดที่ก้อนหินขึ้นไปได้"
✓ 1. Identify
✓ 2. Coordinate ($a = -g$)
✓ 3. $v^2 = u^2 + 2as$
✓ 4. Extreme Check
สมการหลัก: $0 = u^2 - 2g h_{\text{max}} \implies h_{\text{max}} = \frac{u^2}{2g}$
คำตอบสุดท้าย: $h_{\text{max}} = 45\ \text{m}$ (เมื่อใช้ $g = 10$) หรือ $45.92\ \text{m}$ (เมื่อใช้ $g = 9.81$)
Physical Insight & Extreme Case: มวล $m = 2\ \text{kg}$ ไม่มีผลต่อความสูง (Mass Independence) และเมื่อจำลอง $g \to \infty \implies h_{\text{max}} \to 0$ สอดคล้องกับตรรกะทางฟิสิกส์ 100%
Case 3: การไถลลงเนินและการหยุดนิ่งบนพื้นราบที่มีแรงเสียดทาน
✓ Solved • Verified
"ปล่อยวัตถุมวล 4 kg ไถลลงจากยอดเนินลื่นสูง 5 เมตร แล้ววิ่งต่อไปบนพื้นราบที่มีสัมประสิทธิ์แรงเสียดทานจลน์ 0.2 จงหาระยะทางที่วัตถุเคลื่อนที่บนพื้นราบก่อนจะหยุดนิ่ง"
✓ 1. 2-Phase Model
✓ 2. Work-Energy
✓ 3. $mgh = \mu_k mg s$
✓ 4. Multi-Verification
สมการดุลพลังงาน: $E_1 + W_{\text{nc}} = E_2 \implies mgh - \mu_k mg s = 0 \implies s = \frac{h}{\mu_k}$
คำตอบสุดท้าย: $s = \frac{5}{0.2} = 25\ \text{m}$
Boundary & Energy Logic: ทั้งมวล $m$ และ $g$ ตัดกันหมด หากพื้นลื่นสนิทไร้แรงเสียดทาน ($\mu_k \to 0$) วัตถุจะไถลต่อไปเรื่อยๆ อย่างไม่มีที่สิ้นสุด ($s \to \infty$) ตามกฎการอนุรักษ์พลังงานกล
